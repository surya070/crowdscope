# Publication scope

This repository is a curated copy of the completed compound-clearance study and broader prediction follow-up. Frozen simulator, feature, model and protocol files retain their original bytes and hashes. The larger local workspace also contained earlier independent empirical/recovery attempts, intermediate manuscripts and course slides; those are not part of this repository package.

The public `research/compound/audit_comparisons.py` omits only its final cross-check of the unrelated earlier empirical branch and renames that summary flag to `compound_frozen_inputs_unchanged`. All checks of the current compound protocol, source hashes, 240 trajectory hashes, geometry/accounting and saved metrics remain. This adaptation changes no simulator, fitted model, test partition or prediction.

External SiME raw inputs and participant-level records are downloaded from the original host rather than mirrored. Aggregate summaries, calibration traces and frozen settings are included. The archived SiME report has local download/approval narration removed and notes the excluded participant-level files.

The manuscript is the current eight-page course source. The authors must still verify affiliations, approval, public-data reuse requirements and any venue-specific declarations before external submission. No project-wide reuse licence has been inferred from GitHub visibility.
