Request rates are scenario assumptions. Wheelchair use does not establish a need for help. Count intervals assume independent memberships; correlated errors may invalidate that approximation. Changing controls explores a model, not verified staffing requirements.

Probability evaluation: person + trial held out

Raw → calibrated Brier loss (lower is better). Calibration is fitted inside each outer training set; test records are excluded from both fitting stages.

55 positive observations represent seven repeated wheelchair people. Some controls have unknown repeated identities. Model-family selection and earlier data exploration make this an exploratory study.

Connected framework: separate whole-trial replay

Prior-only → calibrated count MAE in nonempty zones (people). These coherent replay models exclude the recording trial, but participants can have appeared in training.
