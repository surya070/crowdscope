# Broader prediction benchmark, version 1

1 November 2026. This is a new exploratory follow-up informed by the previous negative result. All old test outcomes have been inspected. They are not reused as untouched test evidence. The original generator, protocol and A/M/F outputs remain unchanged. The SiME reference replay is separate and does not empirically validate this compound generator.

## Question and information sets

Does supplied relationship information improve remaining-clearance prediction after observed motion and known nominal mobility when broader learning families and a short causal feature history are considered? A/M/F use exactly the original 14/25/34 whitelisted features. All feature construction remains causal with a 0.2 s observation lag. Family/assistance metadata are supplied scenario truth, not detected labels.

Six learning families: linear ridge, RBF kernel ridge, gradient-boosted regression trees, small feed-forward MLP, GRU sequence model, and history-flattened ridge. Static families see the last available feature vector. GRU and history ridge receive nine equally spaced feature vectors over the preceding 1.6 s, ending at t-0.2 s. Each historical vector uses only its own causal observations and backward 0.2 s velocity difference. The historical elapsed-time feature corresponds to its own pseudo-query time. Query checkpoints remain 2,5,10 s. A causal history-control baseline is necessary because history and learner type otherwise change together.

## Equal search opportunity and implementation

Each A/M/F combination receives exactly three candidates within each family, same loss/data/validation rule. Ridge alpha {0.01,0.1,1}. RBF alpha fixed0.1 and length {0.5,1,2}. Gradient boosting: depth {1,2,3}, 200 trees, learning_rate0.05, min_samples_leaf8, squared-error loss, fixed seed101. MLP: one ReLU hidden layer of width {16,32,64}. GRU: one recurrent layer hidden width {8,16,32}, linear last-state output. History ridge uses alpha {0.01,0.1,1}. No other algorithm/hyperparameter search or seed selection.

Both neural families use CPU PyTorch, full-batch AdamW, lr0.003, weight_decay0.01, 400 epochs, weighted MSE on standardised target. Each candidate is the mean of three fixed initialisation-seed predictions (113,227,331); no best-seed reporting. No internal random validation split, early-stopping selection or test-driven epoch changes. This gives equal configuration counts within each feature set, not identical computational budgets across families. Weighted feature scaling and target scaling use training data only; sequence scaling pools the nine history positions with equal history weight. Predictors are refitted at selected settings on train+validation with scalers refitted on those partitions. Neural ensembles preserve the same seeds. Persist all fitted models and validation predictions. Dependencies are pinned and recorded (project-local sklearn1.7.2; bundled Torch2.7.1); CPU threads bounded for reproducibility.

Select the best candidate per family/information set by validation macro MAE. Ties within1e-12 retain listed order. Also select the best family per information set using validation only, ties in order ridge, RBF, boosting, MLP, GRU, history ridge. Final predictions are clipped to [0,180-t]. Every model receives the same training labels and matched partitions. Feature/condition/run identifiers, private gain and future exits are excluded from arrays.

## Outcomes and interpretation

Primary contrast: MAE(M*)-MAE(F*) on the new G5/G6 test, where * is the validation-selected family and setting for that information set. Also report all six family-matched M-minus-F contrasts and every A/M/F metric on both tests. MAE, RMSE and mean underprediction use the original equal-query/run/condition/block/configuration hierarchy. Conditional descriptive 95% intervals use 10,000 paired block resamples within fixed test configurations, holding fitted models fixed. They exclude training/selection/generator/population uncertainty and do not adjust for the multiple exploratory contrasts. No population p-values or categorical superiority claims.

Freeze all source/config/manifest/model hashes and validation selection before new test generation. Independently recompute saved prediction errors and paired block metrics. Verify static vector equals the final history vector, temporal cutoff invariance, no future/private-field dependence and disjoint block/seed namespaces. Preserve convergence failures and unavailable models explicitly; do not silently remove a family. Report actual outcomes, including if F helps some families but not the selected comparison. Broadening models cannot by itself establish real-world relationship benefit, simulator validity, publication novelty or indexed-publication acceptance.
