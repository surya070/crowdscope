# Initial feasibility summary — 4 November 2026

This is a Stage 1 desk assessment, not the Stage 2 raw-data audit.

Recovered prior notes are in `research/prior_evidence/data/`. The initial audit covered eight files; the later completed study covered fourteen audited files and eleven primary trials. Resolve this chronology and recover final manifests before constructing a new inventory.

What is supportable now:

- Recorded head-position trajectories and geometry can support measured zone occupancy, density and movement diagnostics within the observed area.
- Verified wheelchair mappings exist for a small repeated population. This warrants an identifiability pilot, not a promise of reliable unseen-person wheelchair recognition.
- No verified per-track child/age labels, assistant edges or service-demand outcomes have been established in the recovered records.
- Prior data are exposed development evidence. Geometry holdouts alone do not create unseen people.
- SiME's current source permissions and download endpoints need rechecking; today's web retrieval failed. No raw data have been restored or redistributed in this stage.

Recommended route: start with **uncertain supplied mobility metadata plus movement context** for the core planning experiment (plan path C), and run trajectory-based recognition as a separately gated pilot. Promote it into the main framework only if independent labels, grouping and held-out probability scores justify it. Movement profiles are a fallback, not surrogate disability diagnoses.

Planning outcomes will initially require declared synthetic demand scenarios unless real service requests are found (path D). Such an experiment can establish performance under its assumptions, not real staffing effectiveness. Aggregate egress data from the Geoerg meta-analysis is worth inspecting for an external movement/time check, but cannot validate person-level recognition or staffing decisions.

Next audit: recover final trial manifests and identity registries; count independent people; examine connected participant/trial groups; verify labels and usage terms; determine whether a meaningful person-disjoint split exists without viewing new target outcomes.
